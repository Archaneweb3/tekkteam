## Exact interface to PRISM

`installAgentTrading(...,{readLaunchpadScope})`: injected `readLaunchpadScope(agent)` returns `{available:true,scoped:false,reason:null}` ONLY for ledger absence, or `{available:true,scoped:true,reason:null}` for valid immutable binding. Invalid ledger, owner/Agent mismatch, unsupported version, missing table/query failure => `{available:false,scoped:null,reason:<safe code>}`/throw. No permissive false default in real createServer; it always injects FORGE provider. Direct disposable install tests explicitly inject legacy absence for legacy fixtures.

PRISM helper export: `resolveAssociatedCoinPaperPolicy({agent,paperState,receipt,scope}) -> {kind:'GENERAL'|'ASSOCIATED_COIN'|'UNAVAILABLE',mint:string|null,available:boolean,reason:string|null}`. `scope` is provider result, never request/UI data. scope.available!==true -> UNAVAILABLE/failclosed. Valid scoped OR persisted associated targetPolicy requires strict bound confirmed receipt (Agent/owner/solana:101/Success/confirmed/signature/valid mint). Valid absence plus no associated policy -> GENERAL. Invalid present targetPolicy, scope/policy contradiction (including explicit GENERAL on scoped), or unknown provenance -> unavailable, never downgrade. Persisted associated policy on previously ledger-absent state is restrictive/failclosed, not permission to clear policy; it cannot make a scoped Agent general.

PRISM enforces on configure/enable/BOTH tick branches before any market/discovery call and again after awaits/pause/revision/receipt checks. Scoped discovery and wrong overrides/position/intent mint rejected, no auto-conversion/history rewrite. Scope read happens at each operation and after await so concurrent transition is observed. In-flight general configure/enable uses revision/scope recheck and cannot commit once scope entered. Entry transition refuses in-flight using exposed trading operation guard from PRISM: `canEnterLaunchpadScope(agentId) -> boolean` checks locks/enabled/position; FORGE transition calls synchronously in same process before atomic insert, no awaiting between guard and commit. PRISM may instead expose `assertCanEnterLaunchpadScope(id)` throwing409 safe error. This is the one additional return-interface on existing installAgentTrading controller.

Owned trading snapshot adds `paperTargetPolicy` shape as previously agreed. No anonymous state/capability leakage. No signer/RPC/default journal imports in pure helper; existing injected receipt reader remains unchanged, journal errors failclosed.
