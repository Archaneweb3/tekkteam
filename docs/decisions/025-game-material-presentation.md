# 025 — Game-quality presentation system

## Status
Checkpoint 1 only, 2026-09-27. Latest user correction supersedes the universal-glass direction. Brawl Stars is the craftsmanship reference; Sylva informs interaction only. No proprietary graphics are used.

## Context
Rendered Overview has a dominant real office, but equal statistic weights, repeated rounded panels, tiny portraits and oversized empty states flatten its hierarchy. User requests a coherent original game/product material system rather than copied game art. Behance references returned unavailable/blank in this run; no claim is made to have visually verified those project boards. The supplied target image and accessible Sylva material/scene inform the direction without importing their assets.

## Decision
Only game-checkpoint.css is loaded: background, sidebar, hero, primary/secondary buttons and wallet/network controls. Strong lower edges, layered frames and asymmetric small radii replace pill construction. Glass remains selective on floating controls. Product concepts use original 24-unit SVG geometry; Lucide remains the utility family. The real office renderer is unchanged. Employee, New Hires, Trading Desk and Payroll changes are withdrawn from this checkpoint; no global control/plate enrollment is mounted.

Pointer materials are presentation-only, sleeping at rest, reduced-motion aware and removable with the shell. Shared selected plates follow existing active state, never choose application state. Control labels, disabled states, callbacks, routes and data contracts remain authoritative. All route QA uses isolated GET fixtures and blocks writes.

## Ownership / consequences
Lead: tokens, shell/hero, propagation, integration and final QA. Component agent: SVG and control primitives. Overview agent: display markup and local composition. Interaction agent: pointer materials, selection plates and responsive/interaction QA. Existing historical CSS geometry remains; final scoped styles are loaded last rather than deleting sheets with unrelated product contracts.

No changes to backend, wallet, RPC, launch, initial buy, risk/trading calculations, custody, receipts, agent mutations or deployment. No new live actions are performed. This is a local visual release, not a production deployment.
