# 082 — Research-integrated AI Agent Launchpad foundation

## Context

The competitive research found durable asset/operator/activity relationships, different creation and discovery entrances, and post-launch return loops. TEKKTEAM already has strong owner/custody/launch safeguards, but a trading-centered journey and disconnected modules. Copying competitor launch-wallet behavior, automatic trading or fee economics would conflict with current authority and safety. Research observations are not audited competitor execution guarantees.

## Decision

Accept **AI Agent Launchpad** as the product category, with CREATE / DISCOVER / OPERATE modes and independent Agent/token/capability lifecycles. MVP TARGET includes basic verified launch discovery and a persistent linked destination; identity-only Agents remain valid. Public publication is explicit owner opt-in and allowlist-based. Public Agent/Token/Launch/Market/Activity projections derive from canonical authorities, not private owner-state dumps.

No Calls page in MVP. A provenance-backed read-only Signals concept is POST-MVP PLANNED and conditional, not an execution permission. Lifecycle event vocabulary and economic provenance are documentation contracts for future implementation, not a new event store or service. Do not invent creator fees, burns, rewards, guaranteed returns or token-holder rights.

Alternatives rejected: trading dashboard plus launch button (no launchpad return/discovery loop); copying competitor Agent-payer/autostart/economics (changes safety and product semantics without evidence/authority); immediate community Calls or transferable-Agent marketplace (unnecessary new scope).

## Consequences

PRD, SYSTEM, ARCHITECTURE, DESIGN and AGENTS record aligned target responsibilities, privacy and provenance. This supplements decision 081 without altering migration/custody history. Existing owner-payer launch semantics, Paper/Real separation, Mainnet gates, funding/withdrawal, signing and reconciliation remain unchanged. Further implementation requires scoped approval and explicit cross-store event/publication design. No code, schema, feature flags, production or transactions change in this decision.
