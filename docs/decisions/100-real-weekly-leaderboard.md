# 100 — Opt-in production closed-position rankings

6 October 2026. Passive read model; no execution permission.

Only explicitly published owner-bound Agents can rank. Canonical production
LIVE_AUTONOMOUS operations receive an immutable server provenance marker at
reservation; old records, staging and acceptance operations are never relabeled.
Finalized receipts must match execution, signature, message hash and intent.
Chain block time determines the Monday00:00 UTC inclusive to next Monday exclusive
week. Unknown ordering/basis fails closed. No qualifying history means an empty
podium, never fabricated winners.

Full position cycles count once. Entry/exit fees affect integer SOL cost/proceeds;
rent and separately recorded failed-operation expenses are outside closed-position
results. Complete QA cycles are excluded. Finalized failures have no token effect
and do not erase valid basis. ROI uses weighted entry cost and exact comparison.
Only Agent ID, name, character, strategy and aggregates are public. Publication is
default-off, owner-authenticated and revocable. Owner addresses, wallet addresses,
receipts, session data and private diagnostics are not projected.

Independent review accepted accounting/privacy/provenance fixes. Fixture tests
do not establish real trading or production performance; all trading remains OFF.
